| Archivo                             | Para qué sirve                                                                                    | Qué debería contener                                                                                                                                                   |
| ----------------------------------- | ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `context/pedidos.txt`               | Es la “base de datos” simulada de pedidos.                                                        | Los pedidos con código, producto, estado, fecha estimada, transportadora, enlace, etc. No debería tener instrucciones para Llama.                                      |
| `context/politica_devoluciones.txt` | Es la fuente oficial para decidir si una devolución procede.                                      | Reglas como productos retornables, no retornables, productos abiertos, higiene, perecederos, defectuosos, plazos, etc.                                                 |
| `prompts/system.txt`                | Define las reglas superiores del modelo.                                                          | Que use únicamente el contexto, no invente datos, valide evidencia, no exponga razonamiento interno, pida información faltante y responda en español.                  |
| `prompts/role_prompt.txt`           | Define quién es el modelo dentro de EcoMarket.                                                    | Algo como: “Eres EcoBot, asistente de atención al cliente de EcoMarket”. También define tono: amable, profesional, explicativo y orientado a resolver.                 |
| `prompts/instruction_prompt.txt`    | Define **cómo debe analizar el caso** antes de responder. Es uno de los archivos más importantes. | Procedimiento: identificar solicitud → buscar evidencia → contrastar datos/política → determinar decisión → validar → responder explicando el porqué.                  |
| `prompts/pedido.txt`                | Define las reglas específicas para consultas de pedidos.                                          | Cómo buscar el código de seguimiento, qué información entregar, qué hacer si el código no existe o si hay retraso. No debería tener un pedido fijo.                    |
| `prompts/devolucion.txt`            | Define las reglas específicas para devoluciones.                                                  | Verificar código del pedido, identificar producto, consultar política, determinar si procede y pedir datos adicionales si faltan. No debería estar limitado a shampoo. |
| `prompts/negative_example.txt`      | Presenta un caso que fue mal resuelto.                                                            | Una situación donde el modelo pueda equivocarse, por ejemplo aprobar una devolución sin tener el código del pedido.                                                    |
| `prompts/negative_output.txt`       | Muestra la respuesta incorrecta del ejemplo negativo.                                             | Por ejemplo: “Tu devolución ha sido aprobada”, aunque no exista información suficiente.                                                                                |
| `prompts/negative_reasoning.txt`    | Explica **por qué** esa respuesta está mal.                                                       | Debe enseñar qué faltó validar, qué asumió incorrectamente y qué debería haber hecho en su lugar.                                                                      |
| `prompts/positive_example.txt`      | Presenta un caso correctamente planteado.                                                         | Una solicitud con información suficiente para demostrar cómo debe actuar EcoBot.                                                                                       |
| `prompts/positive_output.txt`       | Es el ejemplo de la respuesta ideal.                                                              | Debe tener el nivel de explicación, empatía y justificación que quieres que Llama imite.                                                                               |
